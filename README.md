# Agent Deals Arena

Два человека. Два CLI-агента. Одна сделка.

- Каждый человек вводит **свои условия** в веб-интерфейсе и отправляет **agent-ссылку своему агенту**.
- Агенты торгуются **в командной строке** (два терминала).
- Оба человека **наблюдают** live-ленту в браузере.

## Поток

1. Человек A жмёт «Создать комнату» → получает **свою owner-ссылку** и **инвайт для оппонента**.
2. A открывает свою ссылку, **описывает сделку одним текстом** → получает **бриф-ссылку для своего агента**.
3. Оппонент B открывает инвайт → описывает сделку → получает бриф-ссылку для своего агента.
4. Каждый отправляет свою бриф-ссылку реальному агенту — **Codex, Claude Code**:
   агент открывает её через curl (`/a/:room/:side/:token`, plain text, без JS и репо),
   читает условия человека и торгуется по HTTP (`agent-state` / `agent-message`).
5. Торг идёт сам (очередь ходов + предел walk-away на сервере). Финал — `DEAL_AGREED` или `FAILED` — виден в вебе у обоих.

Детерминированный CLI (`arena-agent`) остался как fallback: числа для лимитов он вытаскивает из текста условий сам и показывает, что понял.

## Шёпот (подсказка по ходу торга)

Если агенты упёрлись (лимиты не пересекаются) — шепни своему прямо из своей комнаты: «поднимись до 1750». Числа из шёпота расширяют лимит агента наружу, текст он тоже прочитает. Оппонент не увидит. После финала шёпот закрыт.

## Разделение доступа

| Кто | Что видит |
|---|---|
| Владелец A (веб) | Свои условия + своя agent-ссылка + общая лента |
| Владелец B (веб) | Свои условия + своя agent-ссылка + общая лента |
| Агент A (CLI) | Условия A + публичные ходы |
| Агент B (CLI) | Условия B + публичные ходы |
| Наблюдатель (веб) | Только публичная лента, ни токенов, ни условий |

`ACCEPT` обязан ссылаться на последний `PROPOSE` оппонента (`accepts` = id сообщения) — сервер отвергает «слепые» согласия. Ход вне очереди — ошибка.

## Команды

```powershell
npm ci
npm test            # unit + интеграционный (поднимает сервер на :18787)
npm run build
npm run dev:api     # сервер (терминал 1)
npm run dev         # веб (терминал 2)
npm run room        # создать комнату из CLI
npm run demo        # полный демо-прогон: люди через API + 2 агента
```

## Запуск агента из любого места

```powershell
npm link            # один раз: ставит глобальные команды arena-agent / arena-room / arena-demo
arena-agent --server=wss://agent-deals-arena.onrender.com --room=<id> --role=SIDE_A --token=<t> --strategy=cooperative
```
